Analytics answers one question: **is Liffy any good?** Not "is it running" — is
it worth having.

Every number on the page comes from your own instance. There is no aggregate
across users, because there is no Liffy server collecting one.

- **Reviews run / completed / failed** — the raw counts. Failed ones are not
  hidden; a high failure count usually means a provider or credential problem.
- **Approval rate** — how many comments you gave a thumbs up.
- **Time to review** — how long it takes end to end.
- **Token efficiency** — approval earned per thousand tokens spent.
- **Comments per review** — how much Liffy says.
- **Category distribution** — what kinds of thing it finds.

Several tiles show an em dash instead of a number. That means **not measured
yet**, not zero. Nothing is a failure until there is enough data to call it
one, and each tile says what it needs.

The page is empty until a review completes. That is honest rather than
unhelpful: an approval rate over zero ratings is not a small number, it is no
number.
