**Security problems do not go in a public issue.** Report them privately through
GitHub's Security tab → *Report a vulnerability*, which keeps the report visible
only to maintainers while a fix is worked out. A public issue is readable by
anyone, including whoever would use it, before there is a fix. `SECURITY.md` in
the repository has the full policy, including what is in scope.

For anything else — a bug, a wrong answer here, something confusing — open a
normal issue. The **Report a problem** button on this page prefills one with
your Liffy version, the provider you are using, and what you searched for, so
you do not have to gather it. It opens GitHub with the text ready; you review it
and submit it under your own account.

Liffy never includes tokens, keys, or your source code in a report.
